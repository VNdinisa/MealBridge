# Decisions log
- Built and run for the Mentor Me Collective (MMC) Google Cloud Launchpad (GCLP) BUILD Capstone / Hackathon (SDG 3: Good Health and Well-Being).
- **Dual Technology Core (Google Cloud + NVIDIA)**: Both technologies contribute meaningful, distinct production capabilities:
  - **Google Cloud Platform**:
    - Backend: FastAPI deployed on **Google Cloud Run**.
    - Storage: **Google Cloud Storage (GCS)** for raw audio uploads, sidecar transcripts, and immutable event logs.
    - Intelligence: **Gemini Models** (Gemini 2.5/2.0 Flash via `google-genai` SDK) for multimodal voice understanding, structured intent parsing (`response_schema`), and compassionate, plain-language older-adult contact scripts.
    - Analytics: Structured operational logs compatible with **BigQuery** for delivery outcome analytics.
  - **NVIDIA Integration (NVIDIA API Catalog / NIM)**:
    - High-performance audio transcription (NVIDIA Riva / Whisper NIM) and/or Safety & Constraint Verification (NVIDIA NIM e.g., Llama 3.3 70B / Nemotron) to cross-audit reassignment proposals against older-adult dietary, mobility, and emergency protocol guidelines before human dispatcher sign-off.
- Local & Testing Determinism: A `sidecar` provider (.txt transcript next to audio) and rules fallback are maintained so pytest suites, CI pipelines, and the Noon Drill run offline with 100% repeatability.
- AI Scope & Human-in-the-Loop:
  - Voice intake -> structured schema -> dual-model verification -> deterministic reassignment ranking -> human dispatcher approval.
  - No change touching an older adult's meal is enacted without dispatcher approval.
